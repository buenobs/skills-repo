## Instalação

No Chatbox, use Skills → Instalar do GitHub com a URL deste repositório. No Claude Code, copie a pasta da skill (em `skills/`) para `~/.claude/skills/`. No claude.ai, compacte a pasta em .zip e envie em Configurações, Capacidades, Skills.
