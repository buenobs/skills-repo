# skills-repo

Repositório das skills personalizadas. Cada pasta é uma skill, com o arquivo `SKILL.md` e, quando houver, as subpastas `references`, `assets` e `scripts`.

## Skills

| Skill | Assunto |
|---|---|
| [artefatos-contratacao-tic](artefatos-contratacao-tic/SKILL.md) | ETP, TR e MGR de contratações de TIC do TRE-ES |
| [curso-ia-setor-publico](curso-ia-setor-publico/SKILL.md) | Cursos e capacitações de IA para o setor público |
| [decora-norma-loop](decora-norma-loop/SKILL.md) | Treino interativo de memorização de normas jurídicas |
| [direito-concursos](direito-concursos/SKILL.md) | Estudo de Direito para concursos e OAB |
| [iamemo](iamemo/SKILL.md) | Memória de trabalho portátil no Notion (IAMemo) |
| [instrucoes-claude](instrucoes-claude/SKILL.md) | Regras gerais de conduta e formatação |
| [mapa-mental-constructor](mapa-mental-constructor/SKILL.md) | Mapas mentais em texto para o XMind |
| [markdown-docs](markdown-docs/SKILL.md) | Documentos em Markdown |
| [notas-abnt](notas-abnt/SKILL.md) | Citações, notas e referências ABNT |

| [tcu-jurisprudencia](tcu-jurisprudencia/SKILL.md) | Consulta à base de dados do TCU |

## Instalação

No Claude Code, copie a pasta da skill para `~/.claude/skills/`. No claude.ai, compacte a pasta em .zip e envie em Configurações, Capacidades, Skills.
