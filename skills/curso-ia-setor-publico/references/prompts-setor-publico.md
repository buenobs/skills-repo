# Prompts Especializados — Contexto do Setor Público

Este arquivo contém exemplos de prompts prontos para usar em exercícios práticos
nos cursos de IA para servidores públicos. Use como material de apoio ao elaborar
atividades hands-on.

> Não inventar resultados. Estes são apenas modelos de prompt — os resultados
> reais dependerão da ferramenta usada pelo servidor durante a capacitação.

---

## Categoria 1 — Redação Oficial

### Ofício
```
Você é um assistente de redação oficial. Redija um ofício formal, seguindo o
Manual de Redação da Presidência da República (4ª edição), com as seguintes
características:
- Destinatário: [cargo e nome]
- Assunto: [tema]
- Finalidade: [solicitar / informar / encaminhar]
- Órgão remetente: [nome do órgão]
- Dados do signatário: [cargo, nome]
Mantenha linguagem formal, objetiva e impessoal.
```

### Parecer Técnico
```
Elabore um parecer técnico sobre [tema], considerando:
- Contexto legal: [legislação aplicável]
- Fatos: [descrição da situação]
- Análise: fundamente com base na legislação citada
- Conclusão: objetiva e fundamentada
Use linguagem técnico-jurídica adequada ao serviço público.
```

### Ata de Reunião
```
Com base nas informações abaixo, elabore uma ata de reunião formal:
- Data, hora e local: [informações]
- Participantes: [nomes e cargos]
- Pauta: [itens discutidos]
- Decisões tomadas: [resumo]
- Encaminhamentos: [responsáveis e prazos]
```

## Categoria 2 — Análise e Síntese

### Resumo de Documento
```
Leia o documento a seguir e produza:
1. Resumo executivo (máx. 150 palavras)
2. Principais pontos de atenção
3. Impactos para [área/órgão]
4. Próximos passos sugeridos

[COLAR TEXTO DO DOCUMENTO]
```

### Comparativo de Propostas
```
Compare as seguintes propostas/alternativas considerando os critérios:
- Custo
- Prazo de implantação
- Conformidade legal
- Impacto para o cidadão

Proposta A: [descrição]
Proposta B: [descrição]

Apresente em formato de tabela comparativa e indique pontos fortes e fracos de cada uma.
```

## Categoria 3 — Atendimento ao Cidadão

### Resposta a Solicitação
```
Elabore uma resposta formal e empática a uma solicitação de cidadão com o seguinte teor:
"[TEXTO DA SOLICITAÇÃO]"

A resposta deve:
- Ser cordial e acessível (evitar jargão)
- Informar o prazo para atendimento
- Indicar o próximo passo para o cidadão
- Seguir os princípios da Lei de Acesso à Informação (Lei 12.527/2011)
```

## Categoria 4 — Apoio à Gestão

### Estruturação de Projeto
```
Estruture um projeto de [nome/tema] no modelo básico de gestão pública:
- Objetivo geral e específicos
- Justificativa
- Público beneficiário
- Ações e atividades
- Indicadores de resultado
- Cronograma resumido
- Recursos necessários (sem inventar valores — marque como [A DEFINIR])
```

### Análise de Risco
```
Identifique os principais riscos para a implantação de [projeto/política] 
no contexto do setor público brasileiro, considerando:
- Riscos operacionais
- Riscos legais e de compliance
- Riscos de segurança da informação
- Riscos de aceitação pelos servidores

Para cada risco, sugira uma medida mitigadora.
```

---

## Notas para o Instrutor

- Sempre oriente os servidores a **revisar criticamente** qualquer saída gerada por IA
- Reforce que a IA pode "alucinar" — inventar informações plausíveis, mas falsas
- Leis, portarias e números de processos NUNCA devem ser aceitos sem verificação
- O servidor é **sempre o responsável** pelo conteúdo assinado, mesmo que gerado com IA
